# Note Linker — Anki 卡片关联插件

给 Anki 笔记建立关联:手动链接、LLM 主题关联。关联以可点击链接的形式存放在每条笔记的「相关卡片」字段中,复习时可直接跳转。

> 说明:这是 Anki 插件,运行在 Anki 内部,直接读写你的牌组,无需经过 AnkiConnect。

## 安装

方式一(推荐):Anki → 工具 → 插件 → 从文件安装,选择 `note_linker.ankiaddon`。

方式二:把 `anki-note-linker` 文件夹整个复制到 Anki 插件目录(工具 → 插件 → 查看文件),并重命名为 `note_linker`。

安装后重启 Anki。需要 Anki 2.1.50 或更新版本。

## 使用

**手动关联**:浏览器(Browse)中选中 2 条以上笔记 → 右键 → Note Linker → 关联所选笔记。所选笔记会两两互链。右键菜单也可清除所选笔记的关联。

**LLM 主题关联(DeepSeek)**:工具 → Note Linker 卡片关联 → LLM 主题关联。把卡片摘要分批发给 DeepSeek(`deepseek-v4-flash`,费用极低),由模型判断哪些卡片属于同一主题——即使字词完全不同也能识别(如「高血压」和 "hypertension")。结果:每张卡片打上主题标签(如 `NL::心脏解剖`),同主题内最相似的卡片互相链接。首次使用会弹窗要 API key(在 platform.deepseek.com 注册获取)。重新运行会替换旧的 `NL::` 标签,但保留已有链接。

**刷新链接样式**:工具 → Note Linker 卡片关联 → 刷新链接样式/快照（快捷键 `Ctrl+Shift+L`）。按字段里已有链接重新生成 HTML,用于更新样式或快照文字,不重新计算关联。

**复习时跳转**:插件会自动在笔记类型中添加「相关卡片」字段,并把它加到卡片背面模板。复习时点击链接即可打开浏览器定位到对应笔记。

## 注意

- 首次给某个笔记类型添加字段会触发一次**完整同步**(Anki 的正常行为),建议先手动同步一次再使用。
- 自动关联会覆写「相关卡片」字段中自动生成的部分,但保留已有链接。
- 删除被链接的笔记后,对应链接会在下次更新该笔记关联时自动清理。

## 配置项

见 Anki 插件配置界面,说明在 `config.md` 中。
